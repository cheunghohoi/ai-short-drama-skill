# 剧本模板（直接填空）

> 复制这个文件，把括号里的内容替换掉。格式不能改：空格、`△`、方括号都是给模型看的信号。

```text
本集出场人物：（角色A）、（角色B）、（角色C）

1-1 （场景名） [（内/外）] [（日/夜）]
△ （一句话写清人物位置和正在做什么，只写拍得到的东西）
【音效】（关键音效，没有就删掉这行）
（角色A）：（情绪或动作）台词一句。
△ （对方的第一反应，具体到动作或表情）
（角色B）：（情绪或动作）台词一句。
△ （情绪转折处的动作）
（角色A）（内心独白）：只在必须交代时用，能改成动作就改成动作。

1-2 （场景名） [（内/外）] [（日/夜）]
△ （转场后的第一句，先交代空间，再交代人）
（角色C）（画外音）：人不在画面里、但声音要出现的话写这里。
△ （结尾动作）
【音效】（收尾音效）
```

## 填写规则

| 位置 | 规则 |
|---|---|
| 出场人物 | 只写有台词或有明确动作的角色，群演不列 |
| 场景题头 | `场号 场景名 [内/外] [日/夜]`，方括号是全角还是半角不敏感，但必须都在 |
| `△` 行 | 一行一件事；超过两件事就拆成两行 |
| 台词 | 每句单独一行，前面不缩进 |
| 声音类型 | 只有三种：直接写名字、`（内心独白）`、`（画外音）` |
| 台词总量 | 750–1000 字；写完自己数一遍 |

## 交稿前自检

- [ ] 没有任何"他觉得""她意识到""气氛很微妙"
- [ ] 每句台词都标了声音类型
- [ ] 开头 3 秒内有冲突
- [ ] 结尾是悬念，没有和解
- [ ] 场景 ≤ 4 个，关键道具 ≤ 5 件
