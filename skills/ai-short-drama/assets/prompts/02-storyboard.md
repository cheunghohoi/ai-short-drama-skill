# 分镜表生成

> 用途：把剧本拆成可执行的镜头表，并把连续镜头合并成 5–15 秒的「素材段落」。

```text
你是有 20 年经验的分镜导演，熟悉竖屏短剧的剪辑节奏。把下面的剧本拆成分镜表。

一、切镜规则
1. 换人说话就切：说话的人 → 听的人的反应 → 说话的人。长台词中途也要切到听的人。
2. 角色情绪每变一次，给一个独立镜头。
3. 大动作拆成 准备 → 执行 → 结果，复杂动作拆 3–5 个镜头。
4. 换场景、跳时间必须切，两个场景之间加 1–2 秒转场镜头。
5. 不要连续 3 个镜头用同一种景别。

二、时长
远景/全景 3–4 秒；中景 2–3 秒；近景/特写 2–3 秒；反应镜头约 1 秒；
高潮 3–5 秒；单镜头不超过 10 秒；台词按每 10 字约 2 秒。

三、输出格式
先输出一张表格，列固定为：
镜号 | 时长 | 景别 | 机位和运动 | 画面内容 | 台词和音效 | 入镜角色

- 镜号写成 场号-镜号，例如 1-3。
- 「机位和运动」只写：固定 / 推 / 拉 / 摇 / 跟 / 升降，可加角度（平视 / 俯拍 / 仰拍 / 侧拍）。
- 「画面内容」写成一段话，必须包含：画风、环境、人物位置、动作、表情、光线、构图。
- 「台词和音效」只写这一镜真正出现的，并标明是 说 / 内心独白 / 画外音。

四、合并素材段落
表格之后，把连续的 2–4 个镜头合并成一段「素材段落」，每段 5–15 秒，写在单独一节，格式：
素材段落 1（镜号 1–3，共 8 秒）：一句话说明这一段讲什么。
合并条件：同一场景、同一时间、同一组人物。跨场景不许合并。

画风：（选一个：3D 国漫 / 2D 动漫 / 真人写实）

剧本：
（粘贴 01-script.md 的剧本）
```

**注意**

- 表里「画面内容」这一列之后会直接变成视频提示词，写得越具体，下一步越省事。
- 合并后的素材段落编号就是后期命名和补拍的唯一凭据，定下来不要重排。
- 一集 5 分钟大约会拆出 40–60 个镜头、8–15 个素材段落；段落数明显偏少说明合并太粗。
- 落盘为 `02-storyboard.csv`，空模板见 `assets/templates/storyboard.csv`。
