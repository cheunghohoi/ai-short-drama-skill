# 角色声色卡提示词
> 用途：让 AI 为剧本里每个有台词的角色生成一张声色卡，之后每段提示词原样复制，保证全剧声音一致。

```
你是短剧的声音指导。根据下面的剧本，为每个有台词的角色写一张声色卡。

输出格式：只输出一张 Markdown 表格，不要前言、不要解释、不要额外章节。
表头固定为：
| 角色 | 年龄感 | 音色 | 语速 | 语气习惯 | 一句话示例 |

填写规则：
1. 角色：只列剧本里真正开口说话的角色。没有台词的角色不要列。按出场顺序排。
2. 年龄感：写听觉年龄，不写剧本设定。格式如「十八九岁的男声」「六十岁上下的男声」。必须能听出来，不许写「年轻」「中年」。
3. 音色：写明暗、粗细、有没有沙、有没有气声。例如「偏亮、略薄」「偏暗、有砂感」「中低、干净」。禁止用「好听」「有磁性」「有感染力」这类无法执行的词。
4. 语速：写快慢和句尾处理。例如「中速偏慢、句尾会拖半拍」「快、几乎不停顿」。
5. 语气习惯：写这个角色惯常的说话态度。例如「平，不太起伏」「客气但疏离」「爱在句中断一下」。
6. 一句话示例：从剧本里挑这个角色一句最有代表性的台词，原样照抄，不要改写、不要补标点。
7. 每格 4–14 个字，不要写成段落。全表不超过 12 行。
8. 同一部剧里，几个角色的声色卡必须能互相区分开：音色、语速、语气三项里至少有两项不同。

表头之后紧接着一行说明，格式固定为：
「以上声色卡写一次定稿，之后每段提示词原样复制，不要换说法。」

剧本：
（粘贴剧本）

画风与年代：
（选一个：3D 国漫 / 2D 动漫 / 真人写实）
```

怎么用：

- 生成的表直接存成一份文件，全剧共用，改一个字都会导致前后声音对不上。
- 每段提示词的【声音】段开头，把这一段说话角色的那一行原样贴进去，再写台词。
- 表里的音色描述是给模型看的，不是给人看的，宁可写得枯燥也不要写形容词。
- 有角色声音已经满意了，另外剪一段干净人声当参考，见 `references/06-voice.md`。
- 只用自己或已获授权的声音做参考，不克隆他人或明星声音。
