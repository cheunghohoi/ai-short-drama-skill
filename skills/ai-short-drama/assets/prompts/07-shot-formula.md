# 单镜头六要素公式

> 用途：把"画面好看一点"这种模糊要求，变成一条模型能执行的镜头描述。适用于出图、出片两条线。

## 模板（复制后填空）

```text
（运镜），（景别），（角度），（主体：谁、什么神情），（运动：动多少）；（光影：方向、软硬、冷暖、明暗）；（焦段），电影质感，真实皮肤纹理，暗部有层次，面部清晰不变形。
```

六个空位一个都不能空，空一个模型就自己猜，猜错就是一次抽卡的钱。

| 空位 | 可选值 | 说明 |
|---|---|---|
| 运镜 | 固定镜头 / 缓慢推近 / 缓慢拉远 / 横移 / 跟随 / 升降 | 说台词时用固定，不要推拉 |
| 景别 | 远景 / 全景 / 中景 / 近景 / 面部特写 / 局部特写 | 与分镜表一致 |
| 角度 | 平视 / 低角度仰拍 / 高角度俯拍 / 侧后方 | 仰拍显压迫，俯拍显弱小 |
| 主体 | 谁 + 一个具体神情（咬牙、怔住、眯眼） | 不要写"表情复杂" |
| 运动 | 几乎不动 / 轻微转头 / 抬手 / 后退半步 | 单一动作，不要串动作 |
| 光影 | 侧光 + 硬光 + 暖 + 暗部保留层次 | 四件事写全：方向、软硬、冷暖、明暗 |
| 焦段 | 35mm（环境）/ 50mm（半身）/ 85mm（特写） | 焦段决定背景压缩感 |

## 示例（自造场景）

```text
固定镜头，面部特写，平视，阿澈咬着牙直视前方，几乎不动、只有眼神发亮并微微抬起下巴；侧光，暖光转白亮，眼中有一道高光，背景虚化；50mm，电影质感，真实皮肤纹理，暗部有层次，面部清晰不变形。
```

## 批量改写提示词

```text
你是电影摄影指导。把下面每个镜头改写成一条单镜头描述，严格按这个模板填空，六个空位一个都不能空：

（运镜），（景别），（角度），（主体：谁、什么神情），（运动：动多少）；（光影：方向、软硬、冷暖、明暗）；（焦段），电影质感，真实皮肤纹理，暗部有层次，面部清晰不变形。

额外规则：
1. 同一场戏内，所有镜头的光影必须完全一致（方向、软硬、冷暖、时间段都相同）。
2. 说台词的镜头用固定机位，不推不拉。
3. 每条只写一个动作，不要串多个动作。
4. 不要出现"电影感""高级感""氛围感"这类无法执行的词。
5. 输出格式：镜号：一句话描述。

景别、运镜、角度的可选词见 references/08-cinematography.md 的词表。

分镜表或画面清单：
（粘贴 02-storyboard.csv 或文字清单）
```

**注意**

- 光影四件事（方向、软硬、冷暖、明暗）是分辨"有电影感"和"平"的关键，最容易被漏。
- 同一场戏锁一套光：上一段"午后暖光"，下一段别写成"冷白光"，否则剪在一起像两部片子。
- 景别和角度要与分镜表一致，不要在这里改节奏。
- 完整的光影方法与词表见 `references/08-cinematography.md`。
