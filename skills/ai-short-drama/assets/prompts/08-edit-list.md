# 剪辑单提示词
> 把剧本和素材清单交给 AI，让它出一份你能照着直接剪的剪辑单。

```
你是短剧剪辑师。我给你这一集的剧本和素材清单，你出一份剪辑单，我要能照着它一条一条剪完，不用再回来问你。

【输入】
剧本：
（粘贴整集剧本）

素材清单（每段一行，编号、时长、内容、已知问题）：
（例：段落 04，7 秒，学徒端面走到桌前说「师父，面坨了」，第 6 秒手指变形）
（例：段落 05，6 秒，老掌柜抬头看他，没说话，全程可用）

素材命名规则：段落号-抽卡次数，例如 04-2 表示第 4 段第 2 次抽卡。选中的那一版请写进「素材号」列。

【必须输出七个部分，顺序不许变】

一、时间线
Markdown 表格，列固定为：序号 | 素材号 | 入点 | 出点 | 头尾剪掉 | 备注
- 按剧情顺序排，一行一段。
- 入点、出点写秒，保留一位小数，例如 2.5。
- 「头尾剪掉」写清剪头还是剪尾、多少秒，例如「头 0.5 秒，尾 0.3 秒」。
- 每行必须满足：入点 < 出点，出点减入点等于这一段实际保留的时长。
- 备注写这一行为什么这么剪，一句话。

二、头尾处理说明
逐段一句话，不写没问题的段。格式：段落号：剪掉什么，为什么。

三、反应镜头覆盖表
Markdown 表格，列固定为：覆盖位置 | 用哪段画面 | 覆盖时长 | 台词是否继续
- 「覆盖位置」写成「第 04 段 3.5–4.5 秒」这种形式。
- 「用哪段画面」写素材号或写「待补生成」。
- 没有需要覆盖的地方，这一栏写「无」，不要留空。

四、待补生成清单
Markdown 表格，列固定为：缺什么 | 多长 | 谁的反应 | 用在哪
- 只列必须补的，能剪能盖的不要放进来。
- 一段都没有就写「无」。

五、配乐分段
Markdown 表格，列固定为：情绪 | 开始 | 结束 | 哪里压低
- 情绪只能从这五个里选：紧张 / 压抑 / 轻松 / 反转 / 收束。
- 开始、结束写全片时间轴上的秒数。
- 「哪里压低」写清在哪些台词前后把配乐按下去，例如「第 04 段 2.0–5.0 秒台词处压低」。

六、全部字幕
Markdown 表格，列固定为：序号 | 时间 | 字幕文字 | 类型 | 说话人
- 一句一行，按时间顺序，不许合并。
- 字幕文字和剧本台词逐字一致，不改写、不缩写、不加剧本里没有的话。
- 类型只能填：说 / 内心独白 / 画外音。
- 时间写「起–止」秒数。

七、待确认问题
如果现有素材做不到「开头 3 秒出冲突、结尾停在悬念」，直接说怎么调顺序或怎么补，不要自己编素材，也不要假装能做到。

【格式约束】
- 只输出这七个部分，前面加一句话总述都不需要。
- 不要写分析过程、不要写建议以外的抒情、不要加「希望对你有帮助」这类结尾。
- 所有时间单位都是秒，不写「0:03」这种格式。
- 表格必须用 Markdown 表格，不要用代码块包。
- 拿不准的地方，宁可留一句「待确认」，不要编一个数字。
```

怎么用、注意什么：

- 素材清单必须一段一行写全，漏写的问题段会被当成正常段排进时间线，剪到那里才发现。
- 剧本要整段发过去，不要只给梗概，否则字幕那一栏会自己编台词。
- 先照「时间线」排一遍，顺序对了，后面几步才省事；顺序不对，反应镜头和配乐都会跟着错。
- 反应镜头和待补生成这两项是花钱项，先数一遍数量，确认后再去跑，不要边剪边补。
- 剪完把实际入点出点回填到 `assets/templates/edit-list.md` 的表里，下一集可以直接照着这个格式填。
