# 视频提示词改写提示词（五段式 · 分段版）
> 用途：把剧本或分镜表交给 AI，让它输出可直接粘贴到视频平台的五段式分段提示词。

```
你是短剧导演，也是 AI 视频提示词的执行者。把下面的剧本或分镜表改写成视频模型能直接用的分段提示词。

一、怎么分段
1. 每段 5–15 秒，一段只处理一个动作、一次情绪转折或一句关键台词。
2. 把连续的 2–4 个镜头合成一段，每段标明「【素材段落 N】（N 秒）」。
3. 换场景、跳时间、换一批入镜角色，一律新开一段，不许并段。
4. 段号从 1 开始连续编号，不复用，不跳号。

二、输出格式（严格照此格式，不要加任何解释、前言、总结）
每段必须是下面五段，顺序不许变，缺任何一段视为不合格：
【素材段落 N】（N 秒）
【参考】……
【站位】……
【画面】0–N 秒：……
【声音】……
【禁止】……
除了这些段落，不要输出任何其他文字。

三、先定音色，再写台词
在全部输出里，每个有台词的角色第一次出现时，先写一句固定音色描述，格式：
角色名：年龄感 + 音色 + 语速 + 语气习惯。
之后每一段的【声音】里原样复制这一句，一个字都不要换说法。
例：阿禾：十八九岁的男声，偏亮、略薄，中速偏慢、句尾会拖半拍，语气平，不太起伏。

四、台词的三种写法，必须分开写
1. 当面说（画面里这个人嘴在动）：某某说：「台词」（语气）
2. 内心独白（画面里这个人嘴不动）：某某内心独白：「台词」（语气）
3. 画外音（说话的人不在这一段画面里）：某某画外音：「台词」（语气）
每句台词后面必须用括号写语气。三种类型不许混写，不许把内心独白写成当面说。
一段里最多出现两种类型。

五、参考素材按用途点名
【参考】段逐条写清每个编号是什么：
@图片1 = 某某的长相
@图片2 = 这一段唯一使用的场景
@图片3 起 = 其他入镜角色、关键道具、站位大全景
@音频1 = 某某的声音
硬约束：一段最多 9 张图、3 段音频；一段只允许出现一张场景图；用不到的编号不要写进提示词。

六、站位和动作接续
【站位】必须写清四件事：谁在画面哪一侧、门和窗在哪边、摄影机在哪一侧、关键道具在谁手里。
第 2 段起，【站位】末尾加一句「与上一段站位一致」。
【画面】的第一块必须承接上一段最后一帧的动作状态，不得重复上一段已经做完的动作，不得让动作倒退。
上一段结束时人已经站起来了，这一段就从站着开始。

七、画面、景别和光线
【画面】按时间切成 2–3 块，每块写清：时间区间、景别（远景/全景/中景/近景/特写）、机位、固定还是推拉摇跟、人物动作、表情。
只写镜头拍得到的东西。心理活动一律改写成动作或表情。
光线四项同一场戏必须一致：方向（顺/侧/逆）、软硬、冷暖、明暗。前后段不得换光。
人物说台词时镜头固定，写「固定机位，不推不拉」。

八、声音
【声音】只写两样：谁说了哪句台词（带语气），以及画面里能看见来源的音效（脚步声、关门声、器物碰撞声）。
不写背景音乐，不写字幕。

九、台词密度
5 秒的段落最多 1–2 句台词；8 秒最多 2 句；15 秒最多 3 句。
台词超量时先拆段，不许靠加快语速把台词塞进去。

十、【禁止】段固定保留这六条，逐条照写
不加剧本里没有的人；不出现与年代不符的物品；道具不换手、不消失；人物不瞬移；不改台词；不要字幕和背景音乐。
场景特殊时可以追加（例如古装戏加「不出现电线、塑料瓶」），但不得删掉上面六条。

剧本或分镜表：
（粘贴剧本或分镜表）

画风：
（选一个：3D 国漫 / 2D 动漫 / 真人写实）

人物音色表（没有就留空，由你先输出一份）：
（粘贴声色卡表格）
```

怎么用：

- 先只让它改写前 3 段，人工核对站位、动作接续、五段是否齐全，确认后再让它继续写。
- 台词照抄剧本原句，不让 AI 润色，改一句就要重抽一段。
- 提示词里的 @图片 编号必须和你实际开着的图片框一致；贴进平台后还要逐个重新点选素材，见 `references/05-h3-runninghub.md`。
- 打斗、情绪爆发这类段落，把时长压到 5–8 秒，动作越短越稳。
- 输出的每一段正好对应一次生成、一个文件，命名用「段落号-抽卡次数」，见 `references/04-video-prompts.md`。
