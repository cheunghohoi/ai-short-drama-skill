# 在 RunningHub 上跑 H3：从注册到下载
> 把写好的五段式提示词和资产图放进在线工作流，一段一段跑出来，按编号下载，不乱不重。

读完你能做到三件事：

- 分清「参考生视频」「图生或首尾帧」「数字人」三种模式各自解决什么问题。
- 走完注册、试跑、上传、贴提示词、改参数、运行下载六步。
- 知道 seed 为什么会让「抽卡」失效，以及怎么绕开。

这一篇是平台操作手册，不讲创作。提示词怎么写看 `references/04-video-prompts.md`，声音怎么统一看 `references/06-voice.md`，花多少钱看 `references/10-cost.md`。

先说一件事：平台界面、按钮位置、套餐价格都会变。下面所有可点的动作按功能描述，数字进表格并注明参考时间。对不上就以你屏幕上看到的为准。

## 三种模式

一个工作流三种用法，差别只在「你给它什么、它给你什么」。选错模式是新手最常见的一次性浪费。

| 模式 | 你给什么 | 它出什么 | 什么时候用 |
| --- | --- | --- | --- |
| 参考生视频 | 提示词 + 1–9 张参考图 + 0–3 段音频 | 一段带动作、对白、音效的镜头 | 日常出片，占九成用量 |
| 图生或首尾帧 | 提示词 + 1 张或 2 张图 | 从这张图开始，或从首帧走到尾帧 | 补镜头、接断点、锁定落点 |
| 数字人 | 提示词 + 1 条驱动音频 + 1 张人物图 | 按这条音频说话的画面和口型 | 口型对不上、声音必须固定时 |

### 参考生视频

解决「让静态资产图动起来并开口」。这是主力模式。

你把角色身份板、场景图、道具图分别喂进去，用 @图片1、@图片2 点名用途，模型据此生成一段有人物、有动作、有台词和音效的画面。

什么时候用：正常排段落的时候。一段素材一次生成，全部走这个模式。

什么时候别用：只是想把某个已有片段延长半秒、或者要一个精确的落点。那属于下面两种。

### 图生或首尾帧

解决「接不上」和「落点不准」。

两种填法：

- 只传一张图：这张图当第一帧，模型往后生成。用来补一个断掉的镜头，或者从某一帧往后延伸。
- 传两张图：第一张当首帧、第二张当尾帧，模型负责补中间这段运动。用来控制「必须从这个姿势走到那个姿势」，比如手从桌上移到门把手上。

什么时候用：

- 上一段结尾和下一段开头差了几帧，需要一段过渡。
- 某一段中间出问题，截下出问题前那一帧、用生图工具改好，再让这个模式从改好的帧往后补一小段。
- 有个必须精确到达的画面（比如必须停在那只碗上），把那一帧当尾帧。

注意：这个模式里只开一个图片框（或两个，首尾帧），其余关掉。多开的框会被当成额外参考，落点就不准了。

### 数字人

解决「声音已经定了，只要口型」。

你给它一条已经配好的台词音频和一张人物图，它按这条音频生成说话的画面。声音不会变，因为声音是你给的，不是它生成的。

什么时候用：

- 角色的声音已经用固定音色配好了，只差画面。
- 参考生视频出来的口型总对不上，改用这个模式兜底。
- 需要某句台词发音绝对准确（台词里有生僻字、专有名词）。

限制：一次只能传一条驱动音频，一条音频对应一段。长台词要拆成几条，逐条驱动，剪辑时接起来。

## 六步操作

### 第 1 步 注册并签到

打开平台站点，用手机号注册登录，进入个人中心找到每日签到入口，点一下。

- 签到送的是平台币，可以直接抵生成费用。
- 每天签一次，攒几天够跑好几段 5 秒。
- 先不要充值，也不要领试用后忘掉自动续费。

### 第 2 步 只用免费币跑通一次，再决定要不要买会员

这一步是为了省钱，也是为了验证流程。

具体做法：拿签到送的币，只做一件事——一个角色、一个场景、一句台词、5 秒。跑一次，看三样东西：

1. 人物长得像不像你给的角色图。
2. 口型能不能对上那句台词。
3. 出来的时长和画幅是不是你要的。

三样都对，再考虑买会员。三样都不对，先回去改提示词和参考图，充钱不解决这个问题。

买会员前确认三件事：

- 套餐是「按币」还是「按座位」，币有没有有效期。
- 是否默认按月自动续费，不需要了在哪关。
- 币会不会过期，别一次囤太多。

价格参考（务必以你屏幕上显示为准）：

| 项目 | 参考值（2026-11 观察）· 以平台实际显示为准 |
| --- | --- |
| 专业版月费 | 约 99 元／月（标价约 159 元／月，常有折扣） |
| 套餐赠送币量 | 约 54,000 币／月（选大额币套餐时） |
| 单币折算 | 约 0.0018 元／币 |
| 一段 5–10 秒消耗 | 约 100 币 |

### 第 3 步 打开工作流，认清界面

打开 H3 工作流（公开分享的工作流打开后直接可用，不用自己搭节点）。界面分三块：

- 左边：素材区。9 个图片框、3 个音频框，以及一组控制开关。
- 中间：提示词框和参数区。
- 右边：运行区。这块平时不用动。

左下角或侧边有一个「禁用」控制区，作用是一键决定哪些图片框、音频框参与本次生成。默认通常只启用图片 1。

工作流内部用到开源节点（本流程用的是 ComfyUI-MiniMaxH3-Easy 一类节点）。节点名和版本会变，不影响你的操作，你只跟外面的框和参数打交道。

工作流从哪来？三种途径，按省事排序：

1. 平台的公开工作流广场里搜模型名或"参考生视频"，挑一个界面上有图片框和音频框的。
2. 别人分享的公开工作流链接（这类链接会失效；失效了退回第 1 条）。
3. 自己用开源节点搭一遍，适合要长期做、想改参数的人。

本仓库不附带工作流文件，也不替任何第三方工作流做背书。凡是要求你先付费、先装客户端、先填账号密码的"工作流"，一律不要用。

### 第 4 步 上传参考图和音频，用禁用框控制启用数量

先想清楚这一段需要几张图，再决定开几个框。开了不用等于让模型参考一张空白图。

按下面的顺序填，编号就是提示词里 @图片1、@图片2 的编号：

| 框位 | 填什么 | 启用条件 |
| --- | --- | --- |
| 图片 1 | 主角角色图或身份板 | 必开 |
| 图片 2 | 这一段的场景图，只放一张 | 有场景就开 |
| 图片 3–4 | 其他入镜角色 | 有第二、第三个入镜角色才开 |
| 图片 5–6 | 关键道具 | 道具是剧情重点才开 |
| 图片 7 | 站位大全景 | 三人以上同框才开 |
| 图片 8–9 | 特殊需求（换装、特定角度） | 按需 |
| 音频 1–3 | 角色声音参考 | 想让声音固定才开 |

操作顺序：

1. 逐张上传，传完看一眼缩略图，确认没传错人。
2. 数一遍这一段实际用了几张图、几段音频。
3. 到禁用控制区，把用到的框打开，其余全部关掉。
4. 再回来看提示词里的 @编号，和开着的框一一对上。

音频不是必须的。第一次做、只想验证流程，音频全部关掉，先看口型和长相。等某一段声音满意了，再剪出来当参考用，见 `references/06-voice.md`。

### 第 5 步 贴提示词、重新点选素材、改参数

提示词从 `references/04-video-prompts.md` 写好的五段式结构整段贴进来。贴完还有两件事必须做。

第一件：重新点选素材。

贴进去的文本里 @图片1 只是一串字符，平台不认。你要在提示词框里把光标放到 @图片1 的位置，删掉，重新输入 @，从弹出列表里选那张图。每张图、每段音频都要重选一遍。

为什么必须重选：文本里的编号和框位是两个系统，只有当你在框里真的选了素材，系统才建立引用。跳过这一步，提示词里的 @图片1 等于没写，模型会把图当普通参考，人物开始飘。

第二件：改参数。新手先按这个来：

1. 模式：日常出片选「参考生视频」。
2. 分辨率：先选最低档（省钱档），验证流程够用。
3. 画面比例：改成竖屏 9:16。工作流默认常常是 16:9，不改成片全是横的。
4. 时长：第一次填 5 秒。
5. seed：先不动，原因见下面的「seed 陷阱」。

改完扫一眼参数区，别漏了画幅——这是最容易忘、后果最明显的一个。

### 第 6 步 运行、验收、按「段落号-抽卡次数」命名

点运行。运行区通常有多个按钮对应不同机器档位，越靠右越快越贵。新手先用默认那个。

出来以后按这个顺序验收，不满意就重抽，不要急着下载：

1. 看长相：角色是不是同一个人，脸有没有变形。
2. 看口型：台词和嘴动对不对得上。
3. 看道具：有没有换手、消失、忽大忽小。
4. 看头尾几帧：开头结尾最容易崩，崩了先考虑剪辑时剪掉（见 `references/07-editing.md`），不一定重抽。

验收通过再下载，命名格式固定为「段落号-抽卡次数」：

- `07-1` 表示第 7 段第一次生成。
- `07-2` 表示第 7 段第二次生成。
- `07-3` 同上。

命名的作用在剪辑时才体现：几十个文件按名字排序，段落顺序自动就对了；同一段有多个版本也不会覆盖。哪个版本留、哪个删，验收时顺手决定，别把三个版本全留到最后。

## 参数速查

| 参数 | 新手怎么填 | 说明 |
| --- | --- | --- |
| 模式 | 参考生视频 | 补镜头换图生或首尾帧；只要口型换数字人 |
| 提示词 | 五段式整段贴入 | 贴完必须重新点选 @ 素材，否则引用失效 |
| 启用图片数 | 2–4 张 | 开着的框数要和提示词里 @图片 数一致 |
| 启用音频数 | 0–3 段 | 第一次做填 0，等有满意样本再当参考 |
| 分辨率 | 最低档起步 | 先验证流程，成片前再升档 |
| 画面比例 | 9:16 | 竖屏平台用；工作流默认多为 16:9，务必改 |
| 时长 | 第一次 5 秒 | 验证通过再出 10–15 秒，省钱 |
| seed | 保持不变 | 换一版才改数字，微调提示词时别动 |
| 负向/禁止 | 写进【禁止】段 | 平台有独立负向框就同样填一遍六条 |
| 机器档位 | 默认档 | 越快的档越贵，试跑用便宜档 |
| 输出命名 | 段落号-抽卡次数 | 例如 `07-2`，剪辑排顺序靠它 |

## seed 陷阱

seed 是随机种子，工作流里通常会写死一个固定数字。固定 seed 加同样的图、同样的提示词，再跑一次结果几乎完全一样。

这带来一个反直觉的后果：你以为在多抽几次卡，其实抽到的都是同一张。

规则只有两条，记住就不会白花钱：

- 想换一版：改 seed，改成别的数字，再跑。
- 只想微调提示词：seed 不要动。

第二条的理由是可控性。你只改了一个词的提示词，seed 不动，出来的差异就只来自那个词，你能判断这个改动是好是坏。seed 也一起改，两个变量同时在动，你永远不知道是提示词起作用还是运气好。

实际操作建议：

1. 每段的第一次生成，用工作流默认 seed。
2. 不满意，先改提示词，seed 不动，出第二版。
3. 提示词已经改不动了，再改 seed，连续出两三个不同 seed 对比。
4. 对比出最好那一版，把它的 seed 记下来，同段后续微调沿用这个 seed。

seed 数字本身没有好坏之分，不必挑「吉利数字」，1、2、3 和 883746 一样有效。

## 省钱习惯

同样的成片，做的人之间成本能差三倍，差别几乎全在习惯上。

1. 先跑 5 秒预览，满意了再出长段。10 秒作废等于两次 5 秒的成本，先短后长是最省的一刀。
2. 多角色先单独试。每个角色先单独跑一段 5 秒，确认长相和声音对了，再把人放在一起出同框长镜头。一上来就三个角色跑 15 秒，失败一次白花一次。
3. 失败先改提示词，不要原样重抽。原样重抽在固定 seed 下基本等于烧币买同一张票。
4. 能剪掉的瑕疵不要重抽。头尾几帧的问题，剪辑时剪掉就没了，见 `references/07-editing.md`。
5. 签到币先花在试跑上。用免费币验证提示词和参数，验证通过再用付费币出正式素材。
6. 只升级选中镜头的画质。先用省钱档跑完全部段落、剪一遍、确定哪些镜头真的进成片，再只对这几个镜头做精细档加工。整集都上精细档是最贵的做法，见 `references/10-cost.md`。
7. 不囤币。会员送的币有有效期，用不完会归零，按月用多少买多少。
8. 关掉自动续费前先看账期。不打算做了就在扣费前关掉，别放到下个账期。

算清一集大概要花多少，用仓库里的 `scripts/cost_estimate.py`，输入段数、时长、抽卡次数就能出估算。价格数字参考 `references/10-cost.md` 的三档画质表，并注意那里的数字同样只是参考区间。
