# 光影与镜头：让画面从能看变成好看
> 画面平，八成不是模型不行，是提示词里缺了光和镜头的具体信息。

读完你能做这些：把"电影感"翻译成四个能写的参数；给一场戏锁一套光，几十段接起来不跳；用一个顺序把镜头六要素写全，减少抽卡次数；卡住时查词表直接抄。

可以直接复制的镜头公式见 `assets/prompts/07-shot-formula.md`。

## 光写具体

**别写"电影感""高级感""氛围感"，模型看不懂形容词。写四件事：光从哪来、硬还是软、冷还是暖、亮还是暗。**

| 维度 | 可写什么 | 不写会怎样 |
|---|---|---|
| 方向 | 顺光、侧光、侧逆光、逆光、顶光、底光 | 只写"打光好"，模型默认正面平光，脸是平的 |
| 硬度 | 硬光（影子边缘清楚）、柔光（过渡慢、影子淡） | 不写就随机，同一场戏里一会儿硬一会儿软 |
| 冷暖 | 暖（偏橙黄）、中性、冷（偏青蓝） | 不写就跟着场景图走，段落之间色温跳 |
| 明暗 | 高调（亮、少阴影）、低调（暗、大面积阴影）、中间调 | 不写默认平均曝光，画面没有重点 |

### 最管用的一招：把顺光改成侧光

- **顺光**：光从摄影机方向打过去，整张脸全亮，几乎没有阴影，看着平。
- **侧光**：光从人物侧面 45 到 90 度打过来，鼻梁、颧骨、下颌出现阴影，脸立刻立体。
- **侧逆光、逆光**：光从背后或侧后方来，勾出一道轮廓，适合孤独、秘密、告别这种情绪。

不要只写一个词，写成一串才有用。可用的句式：

```
侧光，柔光，暖调，中低调，主光在人物左前方约 45 度，右脸留一点阴影。
```

### 明暗对比决定情绪

| 光的组合 | 情绪 | 常见用法 |
|---|---|---|
| 高调 + 柔光 | 安全、日常、回忆 | 白天、家里、和解 |
| 低调 + 硬光 | 压迫、对峙、审问 | 夜里的谈判、逼问 |
| 逆光剪影 | 距离感、身份不明 | 初见、离开、看不清脸的人 |
| 冷暖对比（一处暖一处冷） | 分裂、两难 | 一个人在两盏不同颜色灯之间 |

一个镜头只留一个主光方向。写成"左顺光加右逆光加顶光"这种，模型会画出矛盾的光，脸上一半亮一半黑得很脏。

## 一场戏一套光

**同一场戏，每一段的光必须一模一样：方向、冷暖、时间段三项锁死。**

观众记不住光，但能感觉到"这两段不是同一天拍的"。上一段午后暖光，下一段冷白日光灯，剪在一起像两部片子。

做法：

1. 开拍前给每场戏写一张「光卡」，只有三行：方向、冷暖、时间段。
2. 写提示词时把这张光卡原样复制进每一段的【光影】里，不要凭感觉改。
3. 同一场戏里允许变的只有人物走动带来的明暗变化，方向和色温不动。
4. 光卡落成文件，和资产图放在一起，补拍时照着写，写法见 `references/03-assets.md`。

### 日戏与夜戏两套写法对照

| 项目 | 日戏示例：深夜面馆的白天回忆 | 夜戏示例：雨夜便利店 |
|---|---|---|
| 方向 | 侧光，主光从窗外斜进来，左前方约 45 度 | 侧逆光，主光在人物右后方，冰柜的冷光补正面 |
| 硬度 | 硬光，窗格影子落在桌面上 | 柔光为主，加一点点硬光勾轮廓 |
| 冷暖 | 暖，偏橙黄 | 冷，偏青蓝，全片只留一处暖色（比如关东煮的灯） |
| 明暗 | 高调，亮部通透，阴影浅 | 低调，大面积暗部，亮部只压在脸和手上 |
| 时间段 | 上午，光斜且长 | 深夜，自然光几乎没有，全靠人工光源 |
| 一句话写法 | 侧光，硬光，暖调，高调，上午的斜阳从窗外进来 | 侧逆光，柔光，冷调，低调，冰柜冷光加远处一盏暖灯 |

两套光的切换规则：

- 换场必须换光，同一场不许换。
- 要表现时间流逝（同一地点从早到晚），允许变，但剧本里必须明确这是另一场戏。
- 补拍的段落必须照光卡写，否则补段插回时间线一眼就能看出。

补一句：光卡不是死规定，是防跳的手段。演员走进阴影里，暗部跟着变是正常的；摄影机方向一换，光也跟着换，这个在剪辑里靠反应镜头接得上就行，见 `references/07-editing.md`。

## 镜头六要素

**一个镜头写全六样，少写一样模型就自己猜，猜错就是一次抽卡的钱。**

| 序 | 要素 | 写什么 | 漏写会怎样 |
|---|---|---|---|
| 1 | 运镜 | 固定、推、拉、摇、移、跟、升降 | 模型默认固定，你想推的镜头变成死画面 |
| 2 | 景别 | 远景、全景、中景、近景、特写 | 默认中景，情绪最高点没有特写 |
| 3 | 角度 | 平视、俯拍、仰拍、侧面、过肩 | 默认平视，人物之间的权力关系出不来 |
| 4 | 主体 | 谁，什么神情，手上在做什么 | 模型自己加人，多出剧本外的人 |
| 5 | 运动 | 动多少：几乎不动、轻微、大幅 | 默认乱动，安静的戏拍成走来走去 |
| 6 | 光影 | 方向、软硬、冷暖、明暗 | 见本文件「光写具体」 |
| + | 焦段（建议补） | 广角、标准、中长焦、长焦 | 不写会随机，广角拍脸会变形 |

### 推荐书写顺序

```
运镜 + 景别 + 角度 + 主体 + 运动 + 光影 + 焦段 + 质感后缀
```

质感后缀每次照抄同一句，例如"电影质感，真实皮肤纹理，暗部有层次，面部清晰不变形"。

两个写完整的例子：

```
固定镜头，中景，平视，面馆学徒双手端着面碗从后厨走出来，表情拘谨，
脚步稳、幅度很小；侧光，硬光，暖调，中低调，光从左前方来；
35mm，电影质感，真实皮肤纹理，暗部有层次。
```

```
缓慢推镜，近景转特写，平视偏仰，末班地铁上的陌生人抬起头看向对面，
眼神从涣散到聚焦，只有眼睛和前倾的上半身在动；
侧逆光，柔光，冷调，低调，肩膀有一道亮边；85mm，浅景深，面部清晰不变形。
```

### 六要素怎么取舍

一段只有 5 秒、又只处理一件事的时候，最值钱的两项是**运镜和景别**：先定这两个，其余补齐。

- 想让观众"发现"什么，用推镜加景别收紧。
- 想让观众"被压迫"，用固定加仰拍或俯拍。
- 情绪最高点不要动摄影机，让脸动。镜头一动，观众就分心。

## 词表

写提示词卡住时直接抄。每个词后面一句适用场景。

### 景别

| 中文词 | 适用场景 |
|---|---|
| 大远景 | 交代环境和人物有多小，开场或结尾用 |
| 远景 | 看清人物在哪、周围是什么地方 |
| 全景 | 看清整个人和动作，打斗和进门用 |
| 中景 | 对话的默认景别，看得见表情和手势 |
| 近景 | 情绪戏，脸部占大半画面 |
| 特写 | 关键台词、眼神变化、手部细节 |
| 大特写 | 只给眼睛或嘴，用于极强情绪，一段用一次就够 |
| 过肩 | 两个人对话，带一点对方肩膀，空间关系清楚 |

### 运镜

| 中文词 | 适用场景 |
|---|---|
| 固定镜头 | 台词戏、情绪戏的默认选择，最不容易出错 |
| 缓慢推镜 | 逐渐靠近，用于发现和压迫 |
| 缓慢拉镜 | 逐渐退开，用于孤独和收尾 |
| 摇镜 | 左右转，用于扫过房间或把注意力从 A 带到 B |
| 移镜 | 平行移动，用于跟随走动和展示环境 |
| 跟镜 | 跟在人物后面走，用于代入感 |
| 升降 | 上下移动，用于揭示高处或低处的东西 |
| 环绕 | 围绕人物转，用于关系变化和高潮，容易出错，慎用 |
| 手持微晃 | 紧张、追逐、纪实感，晃太多会晕 |

### 角度

| 中文词 | 适用场景 |
|---|---|
| 平视 | 默认，平等、客观 |
| 轻微仰拍 | 让对方显得有压迫感或高大 |
| 轻微俯拍 | 让对方显得弱势、被审视 |
| 正侧 | 看轮廓和态度，吵架和赌气时好用 |
| 过肩视角 | 对话戏，观众站在一方身后看另一方 |
| 主观视角 | 观众代入角色看到的东西，用于发现和惊吓 |
| 倾斜角度 | 失衡、危险、心理不稳，全片别超过两处 |

### 光位

| 中文词 | 适用场景 |
|---|---|
| 顺光 | 干净、无阴影，适合回忆和明亮日常 |
| 侧光 | 立体感最强，人像首选 |
| 侧逆光 | 勾半边轮廓，神秘又不至于看不清脸 |
| 逆光 | 剪影、距离感，用于身份不明的人 |
| 顶光 | 压抑、审问、地下室感 |
| 底光 | 诡异、恐怖，正常剧情几乎不用 |
| 轮廓光 | 从背后勾一条亮边，把人物从背景里分离出来 |
| 实用光源 | 画面里看得见的灯：台灯、霓虹、冰箱灯，最自然 |

### 色温

| 中文词 | 适用场景 |
|---|---|
| 暖调 | 家、回忆、和解、食物 |
| 中性 | 白天外景、客观叙事 |
| 冷调 | 夜、医院、疏离、秘密 |
| 冷暖对比 | 一个画面里两种色温，表现两难和分裂 |
| 只留一处暖色 | 全冷画面里点一盏暖灯，观众的视线自动被拉过去 |

### 焦段

| 中文词 | 适用场景 |
|---|---|
| 广角（约 24–28mm） | 环境、空间、夸张的前后景；拍脸会变形，别靠近 |
| 标准（约 35–50mm） | 最接近人眼的观感，对话戏通用 |
| 中长焦（约 85mm） | 人像特写首选，背景虚化自然，脸不变形 |
| 长焦（135mm 以上） | 压缩空间，人群里"抽"出一个人，偷窥感 |
| 微距 | 道具、手、眼睛的极近细节 |

焦段只写大概范围就够，模型不需要精确到毫米。

## 常见错误

1. **只写"电影感、高级感"。** 模型不知道你要什么，抽十次还是平。换成光的方向、软硬、冷暖、明暗四个词。
2. **一场戏里光换着写。** 剪起来像两部片子。开拍前写一张光卡，逐段复制。
3. **六要素只写三四样。** 模型自己补，补错就是一次钱。宁可写得啰嗦，也不要留空白让它猜。
4. **一个镜头塞好几种光。** 顺光加逆光加顶光写在一起，会画出矛盾的光，脸上一半亮一半黑。一个镜头一个主光方向。
5. **想用景别解决情绪。** 情绪靠光和角度，景别只解决"看多近"。脸再大，光平还是不感人。
6. **忘了焦段。** 广角拍特写，脸会变形，人物不像同一个人，还会被误当成"角色不一致"。
