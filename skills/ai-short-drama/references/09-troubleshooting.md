# 故障排查：先修最便宜的
> 出现穿帮不要立刻重抽。按"能剪就剪、能补就补、最后才重抽"的顺序处理，同一笔钱能省下大半。

读完你能做这些：判断一个问题该在哪一层解决；对着表格找到症状对应的修法和预防；按发生环节反查是流程哪一步出了错；开机前用一份清单把大部分问题挡在开跑之前。

## 处理优先级

三层，从便宜到贵。**能往下走一步就往下走一步，不要跳级。**

| 层 | 做法 | 代价 | 适用症状 |
|---|---|---|---|
| 1 剪 | 问题只在头尾几帧，剪掉这几帧 | 不花钱 | 手指形变、边缘糊、末尾人物出画 |
| 2 补 | 问题在中间一段：截那一帧改好，用它当首帧只补这一小段 | 一次短生成 | 道具突然变大、眼神飘、脸闪一下 |
| 3 重抽 | 上面两层都救不回来 | 一次完整生成 | 站位错、不是这个人、台词念错 |

三层的时间成本也差很多：剪是几秒钟，补是几分钟，重抽要重新等一次完整生成，还要重新看一遍有没有新问题。

### 重抽前必须先改东西

**原样再点一次运行，结果大概率还是一样。** 尤其当随机种子被固定住的时候，等于花同样的钱买同一张错图。

重抽前至少改一样：

| 改什么 | 怎么改 | 什么时候用 |
|---|---|---|
| 提示词 | 补上漏写的要素：站位、光影、台词类型 | 画面内容不对，人有缺失或多余 |
| 参考图 | 换一张更干净的身份板、场景图、道具图 | 长相不对、场景不对、道具不对 |
| 种子 | 把随机种子换一个数字 | 提示词没毛病，只是想换一版 |

提示词写法见 `references/04-video-prompts.md`，资产图做法见 `references/03-assets.md`，参数与种子在平台上的位置见 `references/05-h3-runninghub.md`。

改的时候一次只改一样，改完能对上因果。同时改三样，成了也不知道是哪样起的作用，下一集还是不会写。

### 补镜头用首帧，不重抽整段

- 问题出在中间：把出问题前的那一帧截下来，用生图工具改好（比如把变大的杯子改回原大小）。
- 把改好的图当首帧，只生成出问题的那一小段，再插回时间线。
- 想指定开头和结尾，就传两张图做首尾帧。
- 插回去之后单独放一条轨，命名 `段落号-fix`，回头查得着。剪辑细节见 `references/07-editing.md`。

补的段落要照同一张光卡写，方向和冷暖不能变，否则插回去明显是另一段。光卡写法见 `references/08-cinematography.md`。

### 先看是哪一层出的问题

症状出现在视频里，原因往往在更上游。**从最上游往下查，别在最后一步硬修。**

| 症状 | 真正该回去改的地方 | 去这里看 |
|---|---|---|
| 每段角色不像同一个人 | 资产图：身份板 | `references/03-assets.md` |
| 场景每段都变 | 资产图：场景图张数 | `references/03-assets.md` |
| 人瞬移、左右颠倒、多出人 | 提示词：站位和禁止栏 | `references/04-video-prompts.md` |
| 念心里话、口型差 | 提示词：台词类型和语气 | `references/04-video-prompts.md` |
| 音色跳变 | 声音参考与声音描述 | `references/06-voice.md` |
| 抽卡结果雷同、比例不对 | 平台参数：种子、比例、时长 | `references/05-h3-runninghub.md` |
| 画面平、段落之间色温跳 | 光卡 | `references/08-cinematography.md` |
| 画面发死、节奏拖、字幕错 | 剪辑 | `references/07-editing.md` |

### 处理记录

一个本子或一张表，跑完一集填一次。填过三集，你会发现踩的坑高度重复。

| 集数 | 症状 | 判断在哪一层 | 做了什么 | 有没有用 | 下次怎么预防 |
|---|---|---|---|---|---|
| 第 1 集 | 第 04 段手指变形 | 剪 | 剪掉末尾 0.5 秒 | 有用 | 不再给手部大特写 |
| 第 1 集 | 老掌柜音色偏低 | 重抽 | 补声音参考后重抽 | 有用 | 声音描述逐段复制 |

### 同一个毛病出现三次，就是流程问题

同一类问题在一集里反复出现，不要再一段一段地修，回去改流程：

| 反复出现的症状 | 该定下来的流程 |
|---|---|
| 角色不像同一个人 | 身份板必须做，并且每段都喂进去 |
| 场景每段都变 | 一段只喂一张场景图，其余关掉 |
| 人瞬移、左右颠倒 | 提示词先写站位，再写动作 |
| 音色跳变 | 声音描述写死，逐段原样复制 |
| 道具忽大忽小 | 道具图写尺寸，提示词里再写一遍 |

判定标准很简单：**修一次是运气，修三次是流程。**

## 故障对照表

症状按出现频率排。修法里带文件路径的，去那份文件看完整步骤。

| 症状 | 最可能原因 | 怎么修 | 怎么预防 |
|---|---|---|---|
| 每段角色长得不一样 | 没喂身份板，或每段只喂了一张正面图 | 把身份板放进参考图，只重抽关键段落；其余段落按「能剪就剪」处理 | 每个主要角色做一张多角度身份板，每段都喂，见 `references/03-assets.md` |
| 场景每段都变 | 一次喂了多张场景图，模型不知道用哪张 | 只留一张场景图，其余在禁用框里关掉，重抽这一段 | 一段只喂一张场景图；对话戏备正打、反打、站位大全景三张，按镜头各挑一张，见 `references/03-assets.md` |
| 人物瞬移，或左右颠倒 | 提示词没写站位 | 补【站位】：谁在左、谁在右、门在哪边、摄影机在哪一侧，然后重抽 | 每段提示词先写站位再写动作，并接住上一段结尾的位置，见 `references/04-video-prompts.md` |
| 角色张嘴念心里话 | 台词没分类型，模型默认所有文字都要念出来 | 在提示词里把内心独白和画外音单独标出，写明不出声、不出现画面 | 剧本阶段就分开标；提示词里"说 / 内心独白 / 画外音"三种分开写，见 `references/04-video-prompts.md` |
| 同一角色音色跳变 | 声音描述每段措辞不同，或没喂声音参考 | 把第一段满意的几句话剪成干净音频，后面每段喂同一段当参考 | 每个角色写一句固定声音描述，逐段原样复制，见 `references/06-voice.md` |
| 长台词画面发死 | 一段里台词太长，镜头一直对着说话的人 | 剪辑里补反应镜头：分离音频，声音不断，上层轨盖 1–2 秒听者反应，见 `references/07-editing.md` | 提示词把长台词拆成两三段；生成时多跑几段反应镜头当存货 |
| 抽卡结果雷同 | 随机种子被固定住了 | 把种子改一个数字再跑 | 想换版本就改种子；只微调提示词时不要动，方便对比，见 `references/05-h3-runninghub.md` |
| 道具忽大忽小 | 道具图没写尺寸，提示词里也没写 | 提示词补上实际尺寸；中间变形的段落用改好的首帧补 | 道具图写尺寸（例如"一只手能握住"），提示词里重复一遍，见 `references/03-assets.md` |
| 画面平，没有电影感 | 只写了"电影感"，缺光的方向、软硬、冷暖、明暗 | 改成侧光、压低暗部、加冷暖对比，然后重抽 | 按四参数写光，一场戏锁一张光卡，见 `references/08-cinematography.md` |
| 口型对不上 | 一段里台词太密、片段太短，或语气没写清 | 缩短台词、加长片段；已经有配音的改用数字人模式按音频对口型 | 5 秒段落最多放一两句；每句写清语气，见 `references/06-voice.md` |
| 多出剧本外的人 | 主体没写清楚，模型自己补人、补群演 | 提示词【画面】里点名"画面里只有谁"，【禁止】里写不加剧本外的人 | 每段都写主体和【禁止】栏，不靠模型自觉，见 `references/04-video-prompts.md` |
| 手或手指变形 | 模型对细节的稳定性有限 | 头尾几帧剪掉；中间的用首帧补 | 避免手部大特写；让道具、袖子、桌面挡住手，剪法见 `references/07-editing.md` |
| 画面里出现文字或乱码 | 模型把招牌、书页、字幕当成画面内容生成 | 剪掉或补；字幕后期另加 | 提示词里写"不要字幕、不要画面文字"，见 `references/04-video-prompts.md` |
| 人物走出画面回不来 | 运动幅度没写，模型自由发挥 | 提示词写"幅度很小，几乎不动"，重抽 | 一个镜头只写一个动作；大动作拆成准备、执行、结果三段，见 `references/04-video-prompts.md` |

### 怎么判断该剪还是该补

拿不准的时候，看一眼问题在时间轴上的位置：

- 在**前 0.5 秒或后 0.5 秒**：直接剪，几乎没有例外。
- 在**中间，但只有 1 秒左右**：先试试能不能用反应镜头盖过去，见 `references/07-editing.md`。
- 在**中间，而且跨了 2 秒以上**：补。
- 问题涉及**长相、性别、人数**：只能重抽，剪和补都救不回来。

还有一个不算修法但常用的一招：**换顺序**。某一段怎么修都不对，如果剧情允许，把它和相邻段换个位置，问题常常就看不见了。前提是不破坏台词逻辑。

### 三个最贵的毛病，多花两分钟

这三个最容易反复出现，也最容易一次改对。按顺序排查，不要跳。

**① 每段角色长得不一样**

1. 先看身份板本身：几个角度是不是同一张脸？不是就重做身份板，别往下走。
2. 再看有没有喂进去：每一段的参考图里都要有这张身份板，只喂场景图没有用。
3. 还不对，就换一版更干净的身份板：白底、全身、正面大图、画面里没有第二个人。
4. 已经跑完的段落，只重抽有正脸和台词的；侧脸、背影、远景的可以留着。

**② 长台词画面发死**

1. 先看台词长度：一段里超过两句，或者单句超过 20 个字，基本都会发死。
2. 还有机会改提示词的，就拆：一句台词拆成两段素材，剪辑时接上。
3. 已经跑完的，在剪辑里救：分离音频，声音连着，上面盖听者反应镜头。
4. 反应镜头要在生成阶段就存货，别等到剪辑才发现一段都没有。

**③ 同一角色音色跳变**

1. 先分清范围：只有一句怪，是这一句的问题；整段都怪，是这一段的问题。
2. 只有一句：只重抽这一句，或者用同一音色重新配一遍贴回去。
3. 整段：补声音参考重抽，声音描述逐段原样复制，见 `references/06-voice.md`。
4. 全片跑完才发现：优先重抽有情绪爆发的那几段，观众对这几段最敏感。

## 开机前自检

三组，一条一条打勾。全部勾完再开始跑，能挡掉上面表格里大半的问题。整套两分钟能过一遍。

### 资产（4 条）

- [ ] 每个主要角色都有一张身份板，正面、侧面、背面是同一张脸、同一套衣服、同一个发型。
- [ ] 场景图里没有混进人；对话戏有正打、反打、站位大全景三张。
- [ ] 关键道具有白底图，并且写了实际尺寸。
- [ ] 全片画风一致：人物、场景、道具是同一种画风，没有一张图风格跑掉。

### 提示词（5 条）

- [ ] 每段都写了【站位】：谁在左、谁在右、门在哪边、摄影机在哪一侧。
- [ ] 台词分了"说 / 内心独白 / 画外音"三种，而且每句都写了语气，不是光给文字。
- [ ] 六要素齐全：运镜、景别、角度、主体、运动、光影。
- [ ] 【禁止】栏写了：不加剧本外的人、道具不换手不消失、人物不瞬移、不改台词、不要字幕、不要背景音乐。

### 参数（4 条）

- [ ] 第一遍用最低画质档预览，先跑 5 秒，满意了再出正式长度。
- [ ] 比例改成 9:16 竖屏（工作流默认往往不是竖屏）。
- [ ] 参考图的张数和提示词里点到的张数一致，用不到的框都关掉。
- [ ] 这次的种子记下来：改了就写清楚改成了多少，方便回溯。

### 每段出来后的检查

这一段跑完，立刻做四件事，不要攒到最后一起看：

1. **看脸。** 暂停，和身份板对比。不像就现在重抽，别等剪的时候才发现。
2. **听台词。** 只听这一句，确认是同一个人的音色，口型和声音对得上。
3. **看头尾。** 首尾各半秒，手指、边缘、人物出画。
4. **改名登记。** 改成 `段落号-抽卡次数`，把种子和问题记进处理记录。

四件事加起来一分钟。几十段跑完再回头找问题，成本是这一分钟的几十倍。

### 勾完之后的习惯

- 三组全勾完再开跑，缺一条就补一条，不要"先跑着看"。
- 跑到一半要改流程，先把已经跑完的段落列出来，判断哪些要重跑，别改完流程又忘了回去补。
- 每集结束把这张清单复制一份存档，标上这一集漏了哪几条、下次先看哪一条。

## 常见错误

1. **一出问题就重抽，提示词一个字不改。** 同样的输入给同样的结果，钱花了问题还在。
2. **一次喂三张场景图想"提高稳定性"。** 模型不知道该用哪张，场景反而更乱。一段只喂一张。
3. **把"角色不像"当成视频模型的问题。** 绝大多数情况是身份板没做，或者没喂进去。
4. **等到剪辑才发现问题。** 几十段都跑完了才看，只能重跑。开机前自检加每段一分钟检查，能省掉大部分返工。
5. **同一段反复微调五六次。** 先跑 5 秒预览，确认了再出正式长度，比反复改 15 秒便宜得多。
