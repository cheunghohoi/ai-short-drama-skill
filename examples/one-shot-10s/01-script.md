# 剧本：10 秒片段

```text
本集出场人物：阿澈

1-1 深夜面馆 [内] [夜]
△ 阿澈把一碗面推过木桌，汤面在灯下冒着白气。他没有抬头。
【音效】门外雨声，排风扇低鸣。
阿澈：（平静，声音不大）这碗面我请。
△ 他的手从碗沿收回来，停在桌沿上，指节发白。
```

## 为什么这样写

| 写法 | 原因 |
|---|---|
| 没有写"他心里愧疚" | 改成"手停在桌沿，指节发白"，镜头拍得到 |
| 台词只有 7 个字 | 10 秒的片段只放得下一句，多了口型必错 |
| 标了"平静，声音不大" | 语气写清楚，模型才知道用什么劲说 |
| 没有一个镜头切到对方 | 片段里只出现一个角色，能省一次一致性问题 |

## 字数核对

台词 7 字 ≈ 1.4 秒。加上两个动作镜头，总长 8–10 秒，符合目标。
