# 示例：一集 10 秒的片段（快速通道的完整产物）

> 这是「一小时做出第一个 10 秒」的完整示例，四个文件对应四个步骤，可以直接拿去对照。

## 目标

只做一个片段：**一个角色、一个场景、一句台词**。目的不是好看，是把整条链路跑通一次。

## 文件

| 文件 | 对应步骤 | 作用 |
|---|---|---|
| `00-brief.md` | 0 立项 | 一句话故事、画风、时长 |
| `01-script.md` | 1 剧本 | 一句台词 + 一个动作 |
| `02-shot-prompt.md` | 4 出片 | 五段式视频提示词 |
| `03-checklist.md` | 全部 | 逐项验收 |

## 关键取舍

- **不做分镜表**：只有一个镜头，拆表没有意义。
- **不做身份板**：只出现一个角色一个镜头，一张全身正面白底图就够。
- **不出 10 秒直接跑 5 秒预览**：先确认长相、口型、站位，再出正式时长。

跑通之后再回到 `references/00-workflow.md` 做整集。
