# 验收清单：10 秒片段

> 照着勾，全过就算跑通了整条链路，可以开始做整集。

## 前两步（文字与图片）

- [ ] `01-script.md` 里没有任何"他心里……""她意识到……"这类拍不到的句子
- [ ] 台词标了声音类型（说 / 内心独白 / 画外音）
- [ ] 角色图是全身、正面、白底、双手垂下、没有表情、**写了鞋子**
- [ ] 场景图里没有人
- [ ] 两张图的画风一致

## 第三步（提示词）

- [ ] 五个段位都在：【参考】【站位】【画面】【声音】【禁止】
- [ ] 每张参考图都点名了用途（@图片1 是什么）
- [ ] 站位写了谁在左、谁在右、摄影机在哪一侧
- [ ] 台词一字不改，语气写清楚了
- [ ] 禁止项里写了：不出现剧本外的人、不换手不消失、不瞬移、不改台词、不要字幕配乐

## 第四步（出片）

- [ ] 先跑的 5 秒预览，不是直接 10 秒
- [ ] 分辨率、画面比例（9:16）、时长三个参数都改过
- [ ] 下载文件按 `段落号-抽卡次数` 命名，例如 `01-1.mp4`

## 第五步（剪辑）

- [ ] 字幕是识别后逐句对过稿的，不是全信自动识别
- [ ] 导出 9:16 / 1080P / 30 帧
- [ ] 手机全屏看一遍，没有手指、道具、换脸、门方向四类穿帮
- [ ] 发布时勾选了 AI 生成声明

## 跑通之后

回到 `references/00-workflow.md` 做整集。整集会多出四样东西：分镜表、角色身份板、反应镜头、剪辑单。
